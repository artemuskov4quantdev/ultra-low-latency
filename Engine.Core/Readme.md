# Low-Latency Event Engine (C#)

This repository is an experimental implementation of a deterministic,
low-latency event processing core inspired by trading and matching engines.

## Goals
- Deterministic event ordering
- Minimal allocations
- Predictable latency
- Explicit concurrency model

## Non-goals
- Production readiness
- Feature completeness
- Framework abstraction

This project is built as a learning and exploration tool.
